# 합주연습기

국악 악보(총보·파트보) PDF를 브라우저에서 읽어, 가야금·대금·해금 같은 선율 악기와 장구·꽹과리 같은 타악기를 늘봄에서 녹음한 소리로 함께 재생하는 연습 도구입니다. 국악관현악단 늘봄 단원 연습용으로 만들었습니다.

- 설치가 필요 없습니다. html 파일 하나를 웹에 올리거나 휴대폰·PC 브라우저에서 열면 됩니다.
- 악보 파일은 브라우저 안에서만 처리되고 어디에도 올라가지 않습니다.
- 변경 내용은 [CHANGELOG.md](CHANGELOG.md)에 날짜별로 적습니다.

---

## 1. 사용법

### 1-1. 지원하는 악보
악보 프로그램에서 **PDF로 저장하거나 PDF 프린터로 인쇄한** 악보만 읽습니다. 어떤 PDF 도구로 만들었는지(Acrobat Distiller, doPDF, pdfFactory, PDF24, PDF-XChange, 한컴 PDF, 'Microsoft PDF로 인쇄' 등)는 상관없습니다. 화면의 '악보 올리기' 아래 **읽을 수 있는 악보 PDF**에도 같은 내용이 있습니다.

| 악보 프로그램 | 읽기 |
|---|---|
| Finale (2004 이후) | 됨 — 가장 많이 시험함(Maestro·Petrucci·Engraver 글꼴) |
| Sibelius | 됨 (Opus 글꼴) |
| MuseScore 2.0 · 2.1 | 됨. 2.0은 기호와 글자를 그림(외곽선)으로 저장해 모양으로 알아보며, 악기 이름·제목은 읽지 못함 |
| Encore | 됨 (Anastasia 글꼴) |
| MuseScore 3 · 4, Dorico | SMuFL 글꼴(Leland·Bravura)을 읽도록 만들었지만 시험한 악보가 아직 없음 |
| 그 밖의 프로그램 (Noteflight, Flat, LilyPond, Guitar Pro, 한글·워드 문서에 그린 악보 등) | 확인 안 됨 |
| 종이 악보를 스캔하거나 사진으로 찍어 만든 PDF, 그림 파일(jpg·png) | **안 됨** — 악보가 그림이라 음표를 읽을 수 없음 |

- 총보(여러 악기 줄이 한 단에 묶인 악보)와 파트보(악기 하나) 모두 됩니다. 높은·낮은·가온음자리표(옥타브 음자리표 포함) 선율 악보와 타악 악보(1줄·5줄)를 읽습니다.
- 정간보는 읽지 못합니다.
- PDF를 크게 확대했을 때 음표 가장자리가 흐려지거나 계단처럼 깨지면 스캔한 그림 PDF입니다.

악보를 읽지 못하면 "악보 기호를 찾을 수 없습니다" 안내가 나옵니다.

### 1-2. 화면 순서 한눈에
화면에는 단계 번호가 붙어 있습니다.
1. **악보 올리기**: 총보 하나와 더할 피아노 악보(왼쪽 상자) 또는 파트보 여러 개(오른쪽 상자). 휴대폰에서는 위아래로 놓입니다.
2. **악기 선택**: 줄마다 선율 / 타악 / 끄기, 악기 소리, 음량. 선율 줄은 쪽빛, 타악 줄은 붉은 띠가 왼쪽에 붙습니다.
3. **빠르기**: 템포 구간과 연습 속도. 노란 칸이 있으면 빠르기 숫자를 넣어야 재생됩니다. (컴퓨터에서는 왼쪽 단)
4. **연주**: 범위·반복을 정하고 재생. 아래 **음원 저장** 칸에서 저장할 마디 범위와 카운트인 등을 따로 정해 **MP3·WAV로 저장**. 그 아래에 마디 지도. (컴퓨터에서는 오른쪽 단, 휴대폰에서는 맨 아래)

화면을 내려 연주 칸이 안 보이게 되면 아래쪽에 **작은 연주 막대**가 떠서, 재생/정지와 지금 마디를 보여 줍니다. [연주 칸]을 누르면 연주 칸으로 돌아갑니다.

### 1-3. 악보 올리기
- 화면 맨 위 설명 아래의 노란 주의 문구처럼, 템포·악기 이름·음표는 자동 인식이라 실제와 다를 수 있습니다. 재생 전에 줄 이름과 빠르기 표를 악보와 맞춰 보세요.
- **총보 업로드**: 총보 PDF를 상자에 끌어다 놓거나 [총보 고르기] 버튼으로 고릅니다. 여러 개를 한꺼번에 고르면(또는 끌어다 놓으면) **줄이 가장 많은 파일을 총보**로, 나머지는 아래의 '더한 악보'로 씁니다.
- **피아노 악보 더하기**: 피아노(건반) 악보처럼 총보와 따로 있는 악보를 총보 상자 아래 [악보 더하기]로 올리면 총보 줄 뒤에 줄로 붙어 함께 연주됩니다. 여러 개를 한꺼번에 고를 수 있고, 처음에는 켜진 상태(선율 줄은 이름으로 악기를 모르면 피아노 소리)입니다. 큰보표 악보는 윗줄·아랫줄이 따로 나옵니다. 총보를 먼저 올려야 쓸 수 있습니다.
- **빼기(✕)**: 올린 총보·더한 악보·파트보는 상자 아래 목록에 나오고, 줄 끝의 ✕로 뺄 수 있습니다. 더한 악보나 파트보 하나를 빼도 나머지 줄의 역할·악기·음량 설정은 그대로 남습니다. 총보를 빼면 더한 악보까지 모두 비워집니다.
- **파트보 업로드**: 악기별 파트보 PDF를 여러 개 한꺼번에 고르거나 끌어다 놓습니다. 나중에 [파트보 추가]로 더 넣으면 목록에 이어 붙고, 이미 있던 파트의 설정은 그대로입니다. 파트보마다 따로 읽은 뒤 **마디 번호**를 기준으로 맞춰 함께 연주합니다.
- 총보를 올리면 파트보 목록이 비워지고, 파트보를 올리면 총보가 비워집니다.
- 장구 파트보 하나만 올리면 장구 장단 연습기처럼 쓸 수 있습니다.
- 처음 열었을 때 나오는 8마디는 예시 장단입니다.

### 1-3-1. 이 악보의 설정 저장 · 불러오기
악보를 올리면 '악보 올리기' 아래에 **이 악보의 설정** 칸이 나옵니다.
- **저장하는 것**: 템포 표(빠르기 숫자·기준 음표·♩=♪ 방향), 연습 속도, rit.·accel. 끝 빠르기와 직접 고친 rit.·accel. 표, 줄마다 역할(선율/타악/끄기)·악기 소리·윗/아랫성부 소리·음량·옥타브·농현, 연주 범위·도돌이표 반복·구간 반복·카운트인·메트로놈·쉬는 마디 박·셈여림, 직접 고친 연주 순서, 음원 저장 칸의 설정과 형식.
- **자동 저장**: 설정을 바꿀 때마다 그 악보에 묶어 이 브라우저에 저장합니다(악보 PDF 내용으로 알아보므로 파일 이름이 바뀌어도 같은 악보면 같은 설정). 파트보 묶음은 올린 파트보 조합마다, 더한 피아노 악보의 줄 설정은 그 PDF마다 기억합니다.
- **자동 불러오기**: 같은 악보를 다시 열면 저장한 설정을 자동으로 불러오고 "불러옴 · 날짜에 저장한 설정"이 표시됩니다. 더한 악보는 파일을 다시 올려야 하며, 올리면 그 줄 설정도 불러옵니다.
- 두 가지 모두 칸의 체크로 끌 수 있습니다. 직접 하려면 [지금 저장], [저장한 설정 불러오기]. [저장한 설정 지우기]는 저장본만 지우고 화면 설정은 그대로 둡니다.
- **다른 기기로 옮기기**: 저장은 그 기기·그 브라우저에만 됩니다. [설정 파일로 내보내기]로 받은 JSON 파일(음정·길이 수정 포함)을 다른 기기에서 같은 악보를 연 뒤 [설정 파일 가져오기]로 넣으면 됩니다.
- 음정·길이 수정(✎)은 예전처럼 따로 늘 자동 저장됩니다.
- 사생활 보호(비공개) 모드에서는 브라우저가 저장을 막을 수 있습니다. 이때는 파일로 내보내 보관하세요.

### 1-4. 악기 선택 (역할 · 악기 · 음량)
악보를 읽으면 **악기 선택** 칸에 줄마다 카드가 생깁니다. 카드에는 줄 번호, 악보에 적힌 이름, 그 줄의 첫 단 그림이 나옵니다. 이름이 잘리거나 이상하면 그림을 보고 고르세요.

- **역할**
  - **선율**: 음높이와 길이를 살려 고른 악기 소리로 연주합니다. 음자리표가 있는 줄만 됩니다.
  - **타악**: 음높이 없이 리듬만 칩니다. 윗성부(기둥이 위로)와 아랫성부(기둥이 아래로)에 소리를 따로 고릅니다.
  - **끄기**: 듣지 않습니다.
  - 처음 설정: 총보는 장구·장고 줄과 이름으로 악기를 알 수 있는 첫 선율 줄 하나만 켭니다. 파트보는 올린 파일을 모두 켭니다.
  - **모두 켜기 / 모두 끄기**로 한꺼번에 바꿀 수 있습니다.
- **악기 소리 (선율)**
  - 녹음: 가야금(25현), 거문고, 양금, 대금, 소금, 피리, 대피리(저피리), 태평소, 생황, 해금, 아쟁, 피아노
  - 합성음: 위 악기들의 (합성음) 판
  - 피아노 녹음은 C4~C5 한 옥타브(반음마다)입니다. 다른 옥타브는 가장 가까운 녹음의 높이를 바꿔 내므로, 아주 낮거나 높은 음은 소리가 조금 어색할 수 있습니다. 녹음이 0.5초쯤 길이라 더 긴 음은 녹음 뒷부분을 이어 붙여 점점 작아지게 만들고(낮은 음일수록 오래 울림), 음이 끝나면 건반을 뗀 것처럼 0.16초에 걸쳐 멈춥니다. 피아노는 악보가 실제 음높이라 옥타브 자동 맞춤을 하지 않습니다.
  - 녹음이 없는 악기는 가장 비슷한 소리로 처음 정합니다: syn.(신디사이저)·건반 → 피아노, Contrabass·Cb.·bass·첼로 → 아쟁, Viola·바이올린 → 해금. 줄마다 바꿀 수 있습니다.
  - 총보에서 줄여 쓴 이름도 알아봅니다: 대피·저피 → 대피리, 생 → 생황, 현·현금·현소·가.1 → 가야금(25현).
  - 이름으로 악기를 알 수 없는 줄은 가야금으로 정하고 "가야금 소리로 정했습니다" 안내를 띄웁니다. 맞는 악기로 바꾸세요.
- **긴 음에 농현 넣기**: 녹음 악기는(양금·피아노 제외) 0.7초 이상인 음에 녹음한 농현·요성·농음을 씁니다. 끄면 곧은 소리만 납니다.
- **옥타브**: 악보보다 한두 옥타브 높이거나 낮춰 냅니다. 악보 음 대부분이 녹음 음역 밖이고 한 옥타브 옮기면 맞는 경우(예: 실제보다 한 옥타브 낮게 적은 태평소)에는 자동으로 맞추고 안내를 띄웁니다. 직접 고르면 그대로 따릅니다.
- **타악 소리**: 장구 따·궁·덩, 꽹과리, 꽹과리 막음, 징, 북 (녹음, 낮고 길게), 북 (녹음, 짧게), 바라, 심벌 (크래시), 하이햇, 베이스드럼, 스네어드럼은 녹음이고 북 (합성음)·북 테는 합성, 그리고 클릭음.
  - 줄 이름으로 처음 소리를 정합니다(성부마다 바꿀 수 있음).

    | 줄 이름 | 윗성부 / 아랫성부 |
    |---|---|
    | 꽹과리·쇠 | 꽹과리 / 꽹과리 막음 |
    | DrumSet·드럼셋 | 하이햇 / 베이스드럼 |
    | 하이햇·Hi-hat·H.H.·심벌(훗)·풋심벌 | 하이햇 |
    | 심벌·Sym·Cym·Crash | 심벌 (크래시) |
    | 타악 줄의 Bass·B.D.·베이스 | 베이스드럼 (선율 줄의 Bass는 콘트라베이스로 보고 타악으로 바꾸지 않음) |
    | 스네어·Snare·S.D.·S.Dr·작은북 | 스네어드럼 |
    | 바라 | 바라 |
    | 징 | 징 |
    | 북·대고·대북 | 북 (합성음) / 장구 궁 |
    | 그 밖 | 장구 따 / 궁 |
  - 같은 녹음 북·바라·심벌·하이햇·베이스드럼을 다시 치면 앞 울림을 짧게 줄여 소리가 뭉개지지 않게 합니다.
  - 심벌에 굴림(트레몰로) 표시가 있으면 녹음한 심벌 롤로 연주합니다. 짧은 롤은 끝에서 가장 크게, 긴 롤은 가장 큰 부분을 이어 붙여 길이를 맞춘 뒤 울림으로 끝납니다.
  - 장구 따와 궁이 같은 박에 나오면 자동으로 덩 소리가 납니다.
  - 빠르게 이어 치는 채편은 둘째 타를 가벼운 '더'로 칩니다.
  - 굴림(트레몰로 표시)은 녹음한 '더러러러'·'개르르르'로, 꾸밈음은 '기덕'의 '기', '그라갱'의 '그·라'로 냅니다.
- **음량**: 0~150%. 반주는 작게, 내 악기는 크게 맞추는 식으로 씁니다.
- **두 줄로 된 악기**(25현 가야금, 양금, 피아노): "가야금 (윗줄)", "가야금 (아랫줄)"처럼 나옵니다. 두 줄을 모두 선율로 켜야 오른손·왼손이 함께 납니다.

예시
- 가야금 연습: 가야금 윗줄·아랫줄 → 선율, 장구 줄 → 타악, 나머지 → 끄기
- 내 파트만 빼고 반주: 내 줄 → 끄기, 다른 줄 → 켜기

### 1-4-1. 솔로 · 음소거 · 좌우 위치
- 줄 카드의 **[솔로 (이 줄만)]**: 그 줄만 들립니다(여러 줄이면 그 줄들만). **[음소거 (이 줄 빼기)]**: 그 줄만 잠깐 끕니다. 줄 설정은 그대로이고 [솔로·음소거 모두 해제]로 원래대로. 저장하지 않습니다.
- **좌우 위치**(선율 줄): 좌우 배치를 켰을 때 그 줄이 들리는 자리. 처음에는 국악관현악 자리처럼 자동.

### 1-5. 템포 구간
- 악보의 빠르기 표시(♩=80, ♩.=52 등)를 찾아 **시작 마디**별로 미리 채웁니다. 숫자를 못 읽은 칸은 노란색입니다. **템포를 인식하지 못한 구간이 연주 범위에 있으면 재생·저장하지 않고**, 템포를 입력하라는 안내와 함께 그 노란 칸으로 옮겨 갑니다. BPM 숫자를 넣은 뒤 다시 재생하세요.
- **기준 음표**: ♩ 4분, ♩. 점4분, ♪ 8분, 𝅗𝅥 2분. 12/8·6/8 장단(굿거리, 자진모리 등)은 보통 점4분입니다.
- **♩=♪ 같은 음표=음표 표시**는 바로 앞 구간 빠르기에서 자동 계산합니다. 앞 구간 숫자를 고치면 따라 바뀝니다.
  - 읽는 방향: 기본은 **왼쪽이 새 박**(예: 박자가 8/8로 바뀌며 `♪=♩`이면 새 8분음표 = 앞의 4분음표)입니다. 악보에 따라 반대로(오른쪽이 새 박) 쓰기도 하므로, 그 구간이 2배 빠르거나 느리게 들리면 칸 아래 **[왼쪽이 새 박]** 단추를 누르세요. 그 악보의 음표=음표 표시가 모두 함께 바뀝니다.
  - 음표=음표 표시와 함께 박자표가 바뀐 뒤, 표시 없이 원래 박자표로 돌아오면 원래 빠르기로 돌아오는 칸을 자동으로 넣습니다("5/4 복귀 (표시 없음)"). 악보에 되돌림 표시를 빠뜨린 경우를 위한 것이니 필요 없으면 ✕로 지우세요.
- **구간 추가 · ✕**로 빠르기가 바뀌는 곳을 더하거나 뺍니다.
- 악보에 rit.·accel.이 있으면 그 끝 빠르기(%)를 정하는 칸이 나옵니다.
- **rit. · accel. 표**: 악보에서 읽은 rit.·accel.·a tempo를 보고 고치거나, [rit. 추가]로 원하는 마디에 넣습니다. 시작 마디·종류·길이(마디 수)·끝 %(비우면 공통 값). 설정에 함께 저장됩니다.
  - 읽는 글자: rit.·rall.·riten.·allargando·점점 느리게 / accel.·stringendo·점점 빠르게(앞에 poco a poco·molto·약간 등이 붙어도 됨) / a tempo·in tempo·Tempo I.
  - 바뀌는 길이: 뒤 점선 끝까지, 점선이 없으면 2마디, poco a poco는 다음 빠르기 표시까지(최대 16마디). 바뀐 빠르기는 a tempo나 빠르기 표의 다음 구간까지 이어집니다.
  - 읽지 않는 것: più mosso·meno mosso(바로 빠르게/느리게), "2nd time only" 같은 반복 횟수 조건, rit. 끝에 새 빠르기로 이어지는 경우의 목표 빠르기(끝 빠르기 %로만 정함).

### 1-6. 연습 속도
템포 전체에 곱해지는 비율(50~150%)입니다. 처음에는 70%쯤으로 천천히 시작하세요. 저장 파일에도 들어가고 파일 이름에 %가 붙습니다.

### 1-7. 연주
- **일시정지와 이어서 재생**: 재생 단추나 스페이스바로 멈추면 그 자리를 기억하고, 다시 누르면 이어서 재생합니다. 연주 중에 속도·악기 등을 바꿔도 멈춘 마디부터 이어서 납니다. 처음부터 들으려면 ⏹ 정지를 누르세요.
- **재생/정지**: 둥근 버튼, 스페이스바(입력칸 밖에서), 마디 지도 옆 [⏹ 정지] 버튼. 진행 막대를 누르면 그 위치로 건너뜁니다.
- **마디 ○부터 ○까지**: 그 범위만 연주·저장합니다. [전곡]은 처음부터 끝까지입니다.
- **도돌이표대로 반복**: 도돌이표, 1·2번 괄호, D.S.·D.C.·코다를 따라 실제 순서대로 연주합니다.
- **구간 계속 반복**: 멈출 때까지 범위를 계속 되풀이합니다(재생에만 적용).
- **카운트인**: 시작 전에 한 마디 박을 칩니다.
- **메트로놈**: 연주 내내 박을 칩니다.
- **쉬는 마디 박 짚기**: 칠 음이 없는 마디에서만 나무 소리로 박을 짚습니다. '박만' 또는 '분박까지'를 고를 수 있고, 연주 칸에 "쉼 3/8마디"처럼 표시됩니다.
- **셈여림 반영**: p, mf, f, 크레셴도 등을 소리 크기에 반영합니다.
- **연주 순서**: 실제로 칠 마디 순서입니다. 반복을 잘못 읽었으면 `1-8, 1-4, 9-16`처럼 직접 고치고, [자동으로]를 누르면 되돌립니다.

### 1-7-1. 소리 다듬기 (연주 칸)
조옮김(반음 단위, 선율만), 기준음 A4(Hz), 늘임표 길이(늘이지 않음~4박), 잔향(없음·조금·보통·많이), 스타카토·트릴 연주(스타카토는 절반 길이, 트릴은 바로 위 음과 번갈아), 좌우 배치(입체 음향). 재생·음원 저장에 함께 적용되고 이 악보의 설정에 저장됩니다. 10분 넘는 소리는 모노로 만듭니다.

### 1-8. 마디 지도
- 칸 하나가 마디 하나입니다. 위 줄은 윗성부(주홍), 아래 줄은 아랫성부(파랑)이고 점 하나가 한 번 치는 자리입니다. 큰 점은 악센트, 작은 점은 꾸밈음, 가로 막대는 굴림입니다.
- **노란 테두리**는 인식이 불확실한 마디입니다(음표 길이가 박자와 안 맞는 등). 악보와 비교해 보고, 다르게 들리면 마디 번호를 알려 주세요.
- 마디를 **누르면** 그 마디부터 재생합니다.
- 마우스를 올리면 **마디 미리보기**가 나옵니다. 위에는 마디 번호와 박자·빠르기·셈여림·반복·✎ 고침·⚠ 확인 필요 표시가 칩으로 나오고, 아래에 켜 둔 악기마다 한 줄씩 나옵니다(악기마다 색이 다름). 맨 아래의 **[▶ n마디부터 재생]** 버튼을 누르면 미리보기가 닫히고 그 마디부터 재생합니다(연주 범위 밖이면 범위를 그 마디부터 끝까지로 바꿈).
  - **박자별 타임라인 보기**: 맨 위 숫자가 박(12/8이면 점4분 4박), 진한 세로줄이 박, 옅은 줄이 잔박입니다. 선율은 음을 막대로 그려 높은 음일수록 위에, 길수록 길게 나오고 막대 안에 음 이름(솔5 등)이 적힙니다. 타악은 윗성부(위 줄)·아랫성부(아래 줄) 점으로, 큰 점은 강세, 줄무늬 막대는 굴림, 작은 점은 꾸밈음입니다. 막대·점에 마우스를 올리면 박 위치와 길이가 나옵니다.
  - **마디 정보 상세 보기**: 악기마다 음을 칩으로 늘어놓아 음 이름과 '몇 박 · 몇분음표'를 글로 보여 줍니다.
  - 고친 음은 테두리로 표시되고, 인식이 불확실한 이유는 아래 노란 칸에 나옵니다.

### 1-8-1. 악보로 보기
**4 연주** 칸 맨 위나 마디맵 칸 위의 큰 단추 **[악보로 보기]**를 누르면(되돌릴 때는 **[마디맵으로 보기]**) 올린 악보 PDF를 그대로 보여 줍니다. 연주하는 동안 지금 마디는 노란 칸, 지금 위치는 빨간 선으로 음표를 따라 움직이고, 다음 단·다음 쪽으로 넘어가면 악보 칸이 따라 내려갑니다(피날레 재생처럼). '연주 위치 따라가기'를 끄면 직접 넘겨 볼 수 있습니다. 악보를 누르면 그 마디부터 재생하고, [−]·[+]로 크기(100~300%)를 바꿉니다. 고른 보기와 크기는 이 기기에 기억됩니다. 총보는 켠 줄 가운데 기준 줄이 있는 단 전체를 표시합니다. 악보·마디맵 칸은 화면 폭 전체를 쓰고, **[화면 가득 보기]**를 누르면 화면 전체에 악보만 보입니다(위쪽 ▶ 재생·일시정지, ✕ 닫기나 Esc로 돌아옴).

### 1-9. 음 수정 (✎)
악보를 잘못 읽어 음정이나 음 길이가 이상한 마디는 직접 고칠 수 있습니다. 음을 더하거나 지우는 기능은 없습니다.

- **수정 창 열기**: 마디 칸의 **✎ 수정** 버튼을 누릅니다. 컴퓨터에서는 마우스를 마디에 올리면 칸 오른쪽 아래에 나타나고, 휴대폰에서는 늘 보입니다. 수정 창은 [닫기], 창 바깥 누르기, Esc로만 닫히므로 마우스를 움직여도 사라지지 않습니다.
- **창 구성**: 켜 둔 줄마다, 성부(윗성부·아랫성부)마다 그 마디의 음이 순서대로 나옵니다. 각 음에는 순번과 박 위치가 붙습니다.
- **선율 음**
  - 높이: **♭ / ♯**는 반음 내리기·올리기, **↓8 / ↑8**은 옥타브 내리기·올리기입니다. 화음은 음마다 따로 고칩니다.
  - 길이: 목록에서 고릅니다(32분·셋잇단 16분·16분·점16분·셋잇단 8분·8분·점8분·셋잇단 4분·4분·점4분·2분·점2분·온음표).
- **타악 음**: 길이만 고칠 수 있습니다.
- **길이를 바꾸면** 같은 성부의 뒤 음들이 그만큼 밀리거나 당겨집니다. 마디 길이를 넘으면 경고가 나옵니다.
- **자동 저장**: 고치는 즉시 이 기기의 브라우저에 저장됩니다. 수정 창에서 고친 음은 색이 다르게 표시되고 "원래 솔5"처럼 원래 값이 함께 보입니다. 마디 지도에는 번호 옆에 ✎가 붙습니다.
- **다시 열 때 자동 적용**: 같은 악보 PDF를 다시 올리면(파일 이름이 달라도 내용이 같으면) 자동으로 적용됩니다. 파트보는 파일마다 따로 적용됩니다. 악보 인식이 바뀌어 원래 음과 맞지 않는 수정은 적용하지 않고 "적용하지 못한 수정 n곳"으로 알려 줍니다.
- **되돌리기**
  - 음 하나: [↺ 되돌리기]
  - 한 마디: [이 마디 모두 되돌리기]
  - 악보 전체: 마디 지도 위의 [수정 모두 되돌리기]
  - 방금 한 수정 취소: Ctrl+Z (Mac은 ⌘+Z). 전체 되돌리기도 Ctrl+Z로 되살릴 수 있습니다.
- **수정 들어 보기**: [▶ 이 마디부터 듣기]를 누르면 그 마디부터 재생합니다.
- **내보내기·가져오기**
  - [수정 내보내기]를 누르면 `곡이름_수정.json` 파일을 받습니다.
  - 다른 기기에서 같은 악보를 올린 뒤 [수정 가져오기]로 그 파일을 고르면 적용됩니다.
  - 다른 PDF 파일(같은 곡을 다시 저장한 경우 등)에 가져오면 적용할지 한 번 묻고, 음이 맞는 곳만 적용합니다.
- **저장 범위**: 저장은 기기·브라우저·주소마다 따로입니다(Claude 페이지, 직접 올린 사이트, PC에서 파일로 연 것이 서로 다름). 휴대폰 브라우저는 오래 쓰지 않은 사이트의 저장 내용을 지우기도 하니, 많이 고쳤다면 내보내 두세요.
- 수정 파일을 보내 주시면 어떤 인식이 자주 틀리는지 보고 해석기 자체를 고치는 데 씁니다.

### 1-10. 저장
- 연주 칸 아래의 **음원 저장** 칸에서 저장할 **마디 범위(몇 마디부터 몇 마디까지)**와 **카운트인·메트로놈·쉬는 마디 박 짚기·도돌이표 반복·셈여림·속도**를 정해 저장합니다. 연주 칸 위쪽의 [음원 저장…] 단추를 누르면 이 칸으로 옮겨 갑니다.
  - 처음에는 재생 설정(연주 범위·옵션·연습 속도)을 그대로 따라갑니다(표시: '재생 설정과 같음'). 저장 칸을 직접 바꾸면 '저장용 설정'이 되어 재생 설정과 따로 움직이고, [재생 설정 가져오기]로 다시 맞출 수 있습니다.
  - 저장해도 재생 중인 소리·연주 범위는 바뀌지 않습니다. 켜 둔 줄, 악기 소리, 음량, 템포 표는 위 설정을 따릅니다.
  - 파일 이름에 곡 제목·마디 범위·속도와 카운트인·메트로놈 여부가 붙습니다(예: 연변목가_7-10마디_100%_카운트인.mp3).
- **MP3 저장(128kbps)**이 기본이고, '형식'에서 **WAV(무압축)**로 바꿀 수 있습니다.
- MP3 변환기는 처음 한 번 인터넷에서 받아 옵니다. 인터넷이 안 되면 WAV로 저장하세요.
- Claude 페이지에서 저장하면 zip으로 묶여 내려받아집니다(압축을 풀면 MP3·WAV).
- **인식 결과 JSON 저장**: 악보를 어떻게 읽었는지(마디, 음표, 템포, 줄 설정)를 파일로 받습니다. 인식 문제를 알릴 때 같이 보내 주면 원인을 찾기 쉽습니다.

### 1-11. 업데이트 이력
맨 위 제목 부분의 **[업데이트 이력 보기]**(또는 맨 아래 판 번호 옆 [업데이트 이력])를 누르면 날짜별로 새로 생긴 기능과 고친 점을 볼 수 있습니다. 내용은 `src/index.template.html`의 `<template id="histTpl">`에 있고, 바뀔 때마다 이 CHANGELOG와 함께 고칩니다. (예전의 '장구 녹음 바꾸기'는 10월 31일에 없앴습니다.)

### 1-12. 휴대폰에서
- 아이폰은 무음 스위치를 켜 둬도 소리가 납니다. 처음 한 번은 재생 버튼을 직접 눌러야 합니다.
- 한 파일 배포판은 9MB 정도라 처음 열 때 조금 걸립니다. 올린 곳이 브라우저 캐시를 허용하면 다음부터는 빨라집니다.
- 긴 곡에서 여러 줄을 한꺼번에 켜면 소리를 만드는 데 몇 초 걸립니다. 진행률(%)이 표시됩니다.

### 1-13. 알아 둘 점
- 추성·퇴성·전성 같은 시김새, 글리산도는 악보 기호를 읽지 못해 나오지 않습니다.
- 쉬는 악기를 숨긴 총보(단마다 줄 수가 다른 악보)는 줄이 엇갈려 읽힐 수 있습니다. 마디 지도와 악보를 비교해 보세요.
- 일부 PDF는 줄 이름 글자를 잘못 담고 있어 이름이 깨져 보일 수 있습니다. 줄 그림으로 확인하세요.

## 2. 저장소 구성

```
합주연습기/
├─ build.py                 html 만들기 (src + banks → dist)
├─ src/
│  ├─ index.template.html   화면(HTML·CSS)과 앱 코드. 빌드 때 아래 모듈이 빈자리에 들어감
│  ├─ score-parser.js       PDF 악보 해석기
│  ├─ outline-glyphs.js     MuseScore 2 외곽선 기호 인식
│  ├─ outline-templates.js  위 인식에 쓰는 기호 견본 (tools/gen_outline_templates.py로 생성)
│  ├─ audio-engine.js       연주 계획(템포·반복·셈여림)과 타악 소리 섞기
│  ├─ melody-engine.js      선율 악기 소리 (녹음 뱅크 재생 + 합성음)
│  └─ samples.json          장구·꽹과리·징·북·바라·심벌·하이햇·베이스드럼 녹음 (16bit PCM, 32kHz, base64)
├─ banks/                   선율 악기 녹음 뱅크
│  ├─ <악기>.mp3            음들을 이어 붙인 녹음 (32kHz 모노)
│  └─ <악기>.json           음 목록
├─ tools/                   녹음 → 뱅크, 기호 견본 만들기
├─ test/                    회귀·성능 테스트 (Node)
├─ README.md
└─ CHANGELOG.md
```

### 2-1. 각 모듈이 하는 일
- **score-parser.js**: pdf.js로 쪽마다 그리기 명령(글자·선·사각형)을 뽑습니다. 그다음 오선과 단을 찾고, 총보면 줄(악기)을 나눕니다. 줄마다 마디선, 음표 머리·기둥·빔·점·쉼표·붙임줄·꾸밈음·트레몰로·음자리표·조표·임시표, 템포·셈여림·반복 기호를 읽어 **마디 목록과 음 이벤트**(시작 박, 길이, 성부, 음높이)를 만듭니다. Finale(Maestro 글꼴), Sibelius(Opus), MuseScore 2(외곽선), Encore(Anastasia)를 지원합니다.
- **audio-engine.js**: 템포 구간·연습 속도·rit./accel.·도돌이표 순서를 반영해 모든 음을 초 단위로 배치하고(`renderPlan`), 타악 소리를 섞습니다(`mix`). 덩 합치기, 덕·더 번갈이, 굴림·꾸밈음 녹음, 카운트인·메트로놈·쉬는 마디 박도 여기서 처리합니다.
- **melody-engine.js**: 선율 음을 소리로 만듭니다. 녹음 뱅크가 있는 악기는 가장 가까운 녹음 음을 골라 음높이를 맞추고(4점 보간), 긴 음은 녹음 가운데를 이어 붙여 늘립니다. 같은 높이의 소리는 한 번만 계산해 다시 씁니다. 뱅크가 없으면 합성음(뜯는 줄 모형, 배음 표, 피아노)을 씁니다.
- **index.template.html**: 화면, 줄 카드, 템포 표, 재생(HTML audio + WAV), MP3 변환(lamejs), 마디 지도·미리보기, 마디별 음 수정(저장·되돌리기·내보내기), 파트보 합치기, 녹음 뱅크 불러오기.

### 2-2. 녹음 뱅크 형식
`banks/<악기>.json`은 `[종류, 음높이, 시작초, 길이초]`의 목록입니다.
- **종류**: `p`는 기본음, `n`은 농현·요성(긴 음용), `t`는 트레몰로
- **음높이**: 실제로 잰 MIDI 번호(소수). 예를 들어 60.13은 C4보다 13센트 높습니다.
- **시작초·길이초**: `banks/<악기>.mp3` 안에서 그 음이 있는 자리

| 악기 | 기본음 음역 | 농현·요성 | 기타 |
|---|---|---|---|
| 가야금(25현) | E♭2–G♯5, 25음 | 13음 | 트레몰로 12음 |
| 거문고 | D♯2–F4, 대현+유현 18음 | 18음 | |
| 대금 | B♭3–E6, 18음 | 18음 | |
| 소금 | B4–B6, 16음 | 14음 | |
| 피리 | A3–F♯5, 12음 | 12음 | |
| 태평소 | A♭4–E♭6, 12음 | 12음(민속악 농음) | |
| 해금 | A♭3–G5, 14음 | 14음 | |
| 아쟁 | G♯2–D♯4, 8음 | 8음(G2–C5) | 높은 음은 농현 녹음으로 |

## 3. 빌드 (html 만들기)

준비물: **Python 3** (추가 설치 필요 없음)

```
python3 build.py
```

| 결과 | 내용 |
|---|---|
| `dist/index.html` | **한 파일 배포판**. 녹음까지 모두 들어 있어 이 파일 하나만 올리면 됩니다(약 9MB). 저장소 맨 위 `index.html`과 같습니다. |
| `index.html` + `version.json` (저장소 맨 위) | **GitHub Pages로 나가는 판**(= `dist/index.html`)과 판 번호. `python3 build.py`가 함께 만듭니다. 웹 주소: https://commst.github.io/scoreplay/ |
| `dist/split/index.html` + `dist/split/banks/` | **가벼운 배포판**. 처음 약 2MB만 받고 고른 악기 녹음만 따로 받아 옵니다. 폴더째 웹 서버에 올려야 하고, PC에서 파일을 더블클릭해 열면 녹음을 못 받아 합성음으로 연주합니다. |

빌드가 하는 일
1. `src/index.template.html`의 빈자리(`/*__PARSER__*/`, `/*__ENGINE__*/`, `/*__MELODY__*/`, `/*__SAMPLES__*/`, `/*__BANK_RANGES__*/`)에 `src/`의 모듈과 장구 녹음을 붙여 넣습니다. 모듈의 `import`/`export` 줄은 이때 지웁니다.
2. 한 파일 판은 `banks/*.mp3`를 base64 글자로 바꿔 `<script type="text/plain" id="bank-<악기>">`로 html 끝에 붙이고, 음 목록(json)은 코드 안에 넣습니다.
3. 웹 페이지 머리(`<!doctype html>` 등)를 씌워 저장합니다.

코드를 고칠 때는 `dist/`가 아니라 **`src/`를 고치고** 다시 빌드하세요. `dist/`는 저장소에 넣지 않습니다(`.gitignore`).

## 4. 도구 사용법 (tools/)

준비물: Python 3, `pip install numpy scipy`, 가야금 도구만 `noisereduce`, 기호 견본만 `fonttools`, 그리고 **ffmpeg**

### 4-1. 새 악기 녹음을 뱅크로 만들기
녹음 방법(권장): 조용한 곳에서 음마다 일정한 세기로 길게(부는·켜는 악기 3~4초, 뜯는 악기는 소리가 사라질 때까지) 연주하고, 음 사이를 1초 이상 띄웁니다. 낮은 음부터 차례로 올라가며 녹음합니다(높이 측정 때 옥타브 오류를 바로잡는 데 씁니다).

1. **mp3를 44.1kHz 모노 wav로 바꾸기**
   ```
   ffmpeg -i 대금_기본음.mp3 -ac 1 -ar 44100 base.wav
   ffmpeg -i 대금_기본음+요성.mp3 -ac 1 -ar 44100 yo.wav
   ```
2. **문턱 정하기**: 소리 구간을 찾는 기준 음량(dB)입니다. 추천값과 찾은 음 개수를 보고, 개수가 녹음한 음 수와 맞을 때까지 숫자를 조정합니다.
   ```
   python3 tools/level.py base.wav          # 추천 문턱과 음 목록
   python3 tools/level.py base.wav -45      # 문턱 -45dB로 다시
   ```
3. **뱅크 만들기**
   - 부는·켜는 악기(대금·소금·피리·태평소·해금·아쟁 등): 기본음 + 요성(농현) 녹음
     ```
     python3 tools/extract_sustained.py base.wav yo.wav banks/daegeum -57.9 -50 2.8 3.2 56k
     ```
     인자: 기본음.wav, 요성.wav, 출력 이름, [기본음 문턱, 요성 문턱, 기본음 최대 길이(초), 요성 최대 길이(초), mp3 비트레이트]. 요성 녹음에서 떨림이 몇 초 뒤에 시작하면 앞부분과 떨림 부분을 자동으로 이어 붙입니다.
   - 뜯는 악기(거문고 등): 기본음계·농현 녹음을 여러 파일로 줄 수 있습니다.
     ```
     python3 tools/extract_pluck.py banks/geomungo p:dae.wav:-44.7 p:yu.wav:-43.7 n:dae_n.wav:-46 n:yu_n.wav:-48.1
     ```
     `p:` 기본음, `n:` 농현, 뒤 숫자는 문턱입니다.
   - 결과: `banks/<이름>.mp3`, `banks/<이름>.json`과 확인용 `banks/<이름>.wav`(지워도 됩니다). 화면에 음마다 잰 높이가 나오니, 음계와 맞는지 확인하세요.
   - **한 파일에 한 음씩** 녹음한 악기(피아노 등)는 `tools/extract_notes.py`를 씁니다. 파일 이름은 보지 않고 음높이를 직접 잽니다.
     ```
     python3 tools/extract_notes.py banks/piano --damper C4.mp3 C#4.mp3 D4.mp3 ...   # --damper: 건반을 뗀 곳 앞에서 자름
     python3 tools/extract_notes.py banks/<이름> --max 3 a.mp3 b.mp3 ...             # 소리가 끝날 때까지(최대 3초)
     ```
4. **앱에 악기 등록**: `src/melody-engine.js`의 `INSTRUMENTS`에서 그 악기 항목에 `bank: '<이름>'`을 넣습니다(예: `daegeum: { name: '대금 (녹음)', kind: 'wind', bank: 'daegeum', … }`). 새 악기라면 `guessInstrument()`에 줄 이름 규칙도 더합니다.
5. `python3 build.py`로 다시 빌드합니다.

`tools/extract_gayageum.py`, `tools/extract_haegeum.py`는 이번 가야금·해금 녹음 전용입니다(음 시작 시각·음계가 코드에 적혀 있음). 새 녹음에는 위 두 도구를 쓰세요.

### 4-1-1. 타악 녹음 한 타 넣기 (북·바라·징·장구 등)
한 번 친 소리를 녹음한 wav/mp3를 `src/samples.json`에 넣습니다(ffmpeg 필요).
```
python3 tools/extract_perc.py src/samples.json 바라 바라.wav 3.6       # 이름, 녹음, 최대 길이(초)
python3 tools/extract_perc.py src/samples.json 북 북.wav 2.4 1         # 끝 숫자: 녹음 안 몇 번째 타(0부터)
```
- 소리 시작 4ms 앞에서 자르고, 봉우리보다 52dB 작아지는 곳(또는 최대 길이)까지 남겨 끝을 서서히 줄이고, 봉우리를 1.0으로 맞춥니다.
- 같은 이름이 있으면 바꿉니다. 이미 있는 이름(따·궁·덩·꽹과리·징·북녹음·북짧게·바라·심벌·심벌롤·하이햇·베이스드럼 등)은 앱이 바로 씁니다. 심벌 롤처럼 천천히 커지는 소리도 잘라 낼 수 있습니다.
- 새 이름이면 `src/index.template.html`의 `SOUND_OPTIONS`에 `['이름', '화면에 보일 이름']`을 넣고, 필요하면 `percDefaults()`(줄 이름 → 처음 소리)와 `src/audio-engine.js`의 `GAIN`(크기)을 고칩니다.
- `python3 build.py`로 다시 빌드합니다.

### 4-2. MuseScore 2 기호 견본 다시 만들기 (보통은 필요 없음)
MuseScore 2.0.3 소스의 `fonts/` 폴더(mscore, bravura, gootville, FreeSerifItalic.ttf)가 필요합니다.
```
pip install fonttools
python3 tools/gen_outline_templates.py <fonts 폴더> src/outline-templates.js
```

## 판 번호와 새 판 알림
- 빌드할 때 그 시각(한국 시각)이 판 번호가 되어 화면 맨 아래에 "합주연습기 2026-10-28 12:46 판"처럼 보입니다. 단원이 어느 판을 쓰는지 이것으로 확인합니다.
- 웹 주소(GitHub Pages)로 열었을 때는 처음 연 뒤 4초, 그 뒤 10분마다, 그리고 다른 앱에 갔다가 돌아올 때 `version.json`을 확인합니다. 열어 둔 화면보다 새 판이 올라와 있으면 위쪽에 "새 판이 나왔습니다 [새로 고침] [나중에]"가 뜹니다. [새로 고침]은 브라우저에 남은 예전 판을 건너뛰고 새 판을 받아 옵니다. 저장한 설정과 음정 수정은 그대로 남습니다.
- 내려받은 html 파일이나 Claude 페이지로 열었을 때는 알림이 뜨지 않습니다(판 번호는 보임).
